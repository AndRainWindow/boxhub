开心电视助手是一款针对安卓设备打造的远程管理工具。我们有了这个软件就可以非常方便管理自己的智能设备了，
比如说盒子电视都可以轻松支持，还可以远程安装各种电视APP，方便用户的使用和安装应用，
新的版本还支持刷第三方固件。


# 9.3版本更新说明

将默认主题色调整为 Material Design 风格蓝色
修复部分安卓 4.4 设备固件备份失败问题
新增固件定制工具模块
设备快速扫描页面：增加连接设备历史记录功能
海思芯片分区表工具，兼容安卓 4.0 至安卓 14 全版本





# 9.2版本更新说明

新增海思芯片分区表制作工具
优化设备信息页面，适配更多规格屏幕
局域网设备发现页面增加多项自定义配置选项
修复部分设备，应用安装失败、卡顿、报错等问题

# 9.1版本更新说明


新增发现局域网设备功能
优化UI和交互体验
修复若干bug

# 9.0版本更新说明


## 为更轻、更快、更稳的电视设备管理体验，开心电视助手极速版全新上线！精简内核、专注核心、启动即连，日常管理更高效。

## 极速版核心亮点
极致轻量化：安装包大幅精简，内存占用更低，低配电脑也流畅运行
启动秒开：启动速度显著提升，打开即可用，无需等待加载
连接加速：ADB 配对与设备连接，局域网秒连，成功率更高
界面极简：保留高频功能，操作一步直达，简单粗暴！

## 新增功能
硬件健康检测：可查看emmc闪存的寿命
备份固件：采用更智能的备份方法，一键备份全部系统分区固件
极速连接模式：一键扫描，省去繁琐步骤（开发中）
极简应用管理：支持批量卸载、启动、查看详情，清爽管理
快捷工具箱：集成常用清理、投屏、文件快传入口
适配优化：全面兼容安卓电视 / 盒子 / 投影，适配更多芯片方案

## 体验优化
重构核心逻辑，运行更稳定、闪退更少
优化 UI 布局，大字更清晰，操作更顺手
降低 CPU 与功耗，长时间使用不发热、不卡顿
精简冗余服务，后台更安静，不占资源

## 问题修复
修复部分设备连接超时、配对失败问题
修复应用列表加载慢、显示异常
修复投屏偶现中断、卡顿
修复已知崩溃与兼容性问题

## 温馨提示
极速版主打轻量快速，适合日常高频管理
更新后建议重启设备及电脑，体验更佳

增加解锁系统测试脚本。

8.0版本更新说明


一、采用 Flutter 技术

开心电视助手本次全面切换至 Flutter 技术框架进行开发。

二、漂亮的 UI

全新的开心电视助手拥有令人惊艳的 UI 设计。整体秉持现代简约风格，在确保功能完备的同时，着重提升了视觉美感，为用户打造舒适的视觉享受。
界面色彩搭配清新明快，营造出活泼且充满活力的氛围，有效激发用户的使用热情。界面中的动态效果自然流畅，使交互过程更具生气与灵动性。
从整体布局到细微元素，均经过精心打磨，充分考虑用户操作习惯，无论是年轻用户追求的时尚便捷，还是老年用户所需的简洁易懂，都能轻松上手，尽情享受操作的乐趣。

三、多平台支持

基于 Flutter 技术强大的跨平台能力，开心电视助手实现了全方位的多平台覆盖。
现在，不管用户使用的是搭载安卓系统的智能电视，还是部分特定品牌的智能电视，抑或是与之关联的安卓手机、平板设备，甚至是 Windows、Mac 等电脑系统，都能便捷地下载并使用开心电视助手。
这意味着，无论用户身处家中客厅，还是外出在外，只要身边有相应设备，都能随时随地通过开心电视助手，实现对电视内容的管理与操作，真正打破了设备与系统的界限，极大地拓展了软件的使用场景，满足了不同用户在多样化场景下的使用需求。

四、现代化

此次更新让开心电视助手全面拥抱现代化。在功能设计上，紧密贴合当下前沿的技术趋势与用户交互习惯，融入诸多创新理念，为用户带来更高效、智能的操作体验。从技术架构层面来看，依托 Flutter 以及一系列现代化技术栈，
软件性能得到大幅优化，响应速度显著提升，运行稳定性更强。同时，对整体架构进行了深度优化，使其具备卓越的扩展性与兼容性，能够从容应对未来不断变化的技术发展以及用户日益多样化的需求，始终在智能电视助手领域保持领先地位。

五、文件管理

开心电视助手的文件管理功能迎来了全面升级。用户现在可以更加便捷地对电视及关联设备中的文件进行分类、查看、编辑、复制、移动、删除等操作。软件支持丰富的文件格式，
不仅涵盖常见的文档、图片、视频格式，还能完美识别各类压缩包等特殊格式文件。新增的文件搜索功能尤为实用，用户只需输入关键词，就能快速定位到所需文件，极大地提高了文件查找效率。
此外，文件备份与恢复功能的加入，为用户数据安全提供了坚实保障，彻底消除了用户对文件丢失或损坏的担忧。

六、应用管理

应用管理功能焕然一新。用户能够清晰直观地查看电视及关联设备中已安装的所有应用，详细信息包括应用名称、版本号、大小、安装时间等。同时，软件支持对应用进行批量操作，例如批量卸载不需要的应用、批量更新应用至最新版本，节省了大量操作时间。
对于一些系统自带但用户无需使用的应用，用户也可以进行禁用操作，从而释放宝贵的系统资源，提升设备运行速度。
值得一提的是，新增的应用权限管理功能，使用户可以根据自身需求，灵活设置每个应用的各项权限，如摄像头、麦克风、通讯录等权限，有力地保护了用户的个人隐私安全。

七、进程权限

在进程权限方面，开心电视助手为用户提供了更为精细的控制手段。用户可以实时监控当前设备正在运行的所有进程，清晰了解每个进程的资源占用情况，包括 CPU、内存、网络等方面的使用详情。
对于那些占用资源过高，可能影响设备性能的进程，或者存在安全隐患的可疑进程，用户可直接在软件中进行强制停止操作，从而优化设备性能。
此外，针对不同进程的权限设置，用户也能进行个性化调整，在确保系统运行安全稳定的同时，充分满足自身特定需求。比如，用户可以限制某些后台进程的网络访问权限，防止其在后台偷偷消耗流量。

八、调试终端

全新上线的调试终端功能，为开发者以及高级用户带来了极大便利。在调试终端中，用户可以输入各类命令，对电视及关联设备进行深度调试与操作。
该功能支持常见的 ADB 命令，同时还提供了一些自定义命令扩展，方便用户根据自身实际需求进行灵活配置。无论是进行设备连接测试、安装应用程序、执行脚本文件，还是对电视系统进行一些底层设置调整，都能通过调试终端轻松完成。
并且，调试终端会提供详细的命令执行反馈信息，帮助用户及时了解操作结果，快速排查可能出现的问题。
